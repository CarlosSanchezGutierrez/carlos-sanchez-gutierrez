# Carlos Sánchez Gutiérrez

Personal website and visual timeline.

**Live domain:** https://carlossanchezgutierrez.com

## Structure

- `index.html` — single-page site content
- `styles.css` — layout, typography and colors
- `script.js` — graduation countdown
- `assets/` — original illustrative SVG diagrams

The site is static and has no build step. Vercel can deploy it from the repository root; connect this repository to the Vercel project and assign the domain there.

The SVG diagrams are illustrative placeholders. Replace them with approved project photography and public materials as they become available.
